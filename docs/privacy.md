# howieip-studio 发布助手 · 隐私政策

更新日期：2026-11-18

howieip-studio 发布助手（以下简称「插件」）是一个在你自己的浏览器里运行的发布填写工具。

## 我们收集什么

**不用「AI 写文案」时，什么都不收集**：插件不向开发者或任何第三方发送你的数据。

**只有你主动使用「AI 写文案」时**，插件会把下面这些发到知识站（www.mdldm.club）：

- 连接账号：你在知识站页面上确认授权后，插件拿到一张「howieip-studio 专用通行证」（只能用来写文案，拿不到你的 AI Key 或密码），保存在本机 `chrome.storage.local`，点「断开」即删除。
- 生成文案：你填写或确认的视频素材（标题、口播稿/字幕/要点文字），用于生成各平台文案；知识站只记录你用了几次（用于免费次数和会员额度），不保存素材原文。素材会经知识站转给 AI 模型服务生成文案。

插件不会把你的视频、封面、其他文件或浏览记录发出去。

## 插件在本机处理的数据

- 你选择的本地文件夹（Obsidian 库、视频发布目录）的访问授权，只保存在浏览器本地（IndexedDB）。
- 读取你指定的笔记、图片、`publish.json`、视频和封面文件，只用于填写到你自己打开的平台页面。
- 填写进度和设置保存在 `chrome.storage.local`。

## 权限用途

| 权限 | 用途 |
|---|---|
| `debugger` | 把本地视频、封面文件交给各平台的上传框（大文件不经过页面内存），并用真实键盘、鼠标事件输入文字 |
| `scripting` | 在 X 长文编辑页插入内容 |
| `tabs` | 在后台打开各平台的上传页 |
| `sidePanel` | 侧边栏界面 |
| `storage` | 保存设置和进度 |
| `notifications` | 填写完成后通知你 |
| 各平台域名 | 只在这些创作者后台页面里填写：B站、小红书、抖音、视频号、YouTube、X、Instagram |
| `www.mdldm.club` | 只用于「AI 写文案」：连接知识站账号、生成文案 |
| `127.0.0.1:8765` | 可选的本机开发桥接，只在「加载已解压的扩展程序」时启用，不连接外网 |

## 不做的事

不读取、不上传你的账号密码和 Cookie；不替你点「发布」；不做点赞、评论、私信、关注等互动操作。
